───────────────────────────────────────────────────────────────
🆘 문제 해결
───────────────────────────────────────────────────────────────

Q: Node.js가 없어요
A: https://nodejs.org/ → LTS 버전 다운로드

Q: 포트 3000이 사용 중이에요
A: vite.config.js에서 포트 변경 (3000 → 3001)

Q: npm install 오류
A: rm -rf node_modules && npm install

Q: 화면이 안 나와요
A: F12 → Console에서 오류 확인

Q: 레시피가 안 보여요
A: localStorage 초기화 → F12 → Application → Local Storage
