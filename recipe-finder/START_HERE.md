# 🎯 여기서 시작하세요!

## 🚀 3단계로 localhost:3000 실행

### 1️⃣ 터미널 열기
- **Windows**: Win+R → `cmd` 입력
- **Mac**: Cmd+Space → `terminal` 입력

### 2️⃣ 프로젝트 폴더로 이동
```bash
cd recipe-finder
```

### 3️⃣ 설치 및 실행
```bash
npm install
npm run dev
```

✅ **완료!** 브라우저에서 http://localhost:3000 자동 실행

## 🆘 문제 발생?

### 1. Node.js 없음
→ https://nodejs.org/ 다운로드

### 2. 포트 3000 사용 중
```bash
# vite.config.js에서 포트 변경
# port: 3000 → port: 3001
```

### 3. 패키지 오류
```bash
rm -rf node_modules
npm install
```
