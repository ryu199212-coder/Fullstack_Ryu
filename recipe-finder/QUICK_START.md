# 🚀 빠른 시작 가이드 - localhost:3000 실행하기

## ⚡ 3단계로 바로 실행!

### 1️⃣ 패키지 설치
```bash
npm install
```

### 2️⃣ 개발 서버 실행
```bash
npm run dev
```

### 3️⃣ 브라우저 자동 실행
자동으로 **http://localhost:3000**이 열립니다!

---

## 📌 명령어 모음

```bash
# 개발 서버 실행 (포트 3000)

npm run build

# 프로덕션 미리보기
```

## 🔑 주요 기능 테스트

1. **로그인**: 우측 상단 "로그인" 버튼
2. **레시피 보기**: 메인 화면에서 레시피 카드 클릭
3. **검색**: 상단 검색창에 "김치" 입력
4. **카테고리**: "한식", "양식" 등 탭 클릭
5. **즐겨찾기**: 레시피 카드의 ❤️ 아이콘
6. **레시피 작성**: 로그인 후 "레시피 작성" 버튼
7. **마이페이지**: 로그인 후 프로필 이미지 클릭 → "마이페이지"
8. **프리미엄**: 상단 "✨ 프리미엄" 배지 클릭
9. **TOP 작성자**: 하단 "이달의 TOP 20 작성자" 확인

## ⚠️ 문제 해결

### 포트 3000이 사용 중인 경우
```bash
# vite.config.js 파일 수정
# port: 3000 → port: 3001
```

### npm 오류
```bash
# node_modules 삭제 후 재설치
rm -rf node_modules package-lock.json
npm install
```

### 화면이 안 나올 때
1. 브라우저에서 F12 (개발자 도구)
2. Console 탭에서 오류 확인
3. localStorage 초기화: Application → Local Storage → 전체 삭제
